# Surface Brief: Portfolio (Home / Showcase)

## Scope and Mode
- Scope: Primary Portfolio Surface (`index.html` / `src/App.tsx`)
- Visitor Mode: Experience (visitor is inside the work; artifact leads from the first viewport)

## Audience and Intent
Recruiters, engineering leads, open-source collaborators, and fellow developers evaluating Meet Rathod's public Python, Discord bot, networking, and FastAPI repositories.

## Direction contract

THESIS: Real public repositories presented on warm architectural stone and blueprint cobalt with interactive code previews, pulsing system diagrams, and spring-animated project inspection, refusing generic dark-mode developer templates.

OWN-WORLD: Stone-blueprint palette (#dfdedb warm stone ground, #d3d2ce surface, #26251e charcoal ink, #2456d6 blueprint cobalt accent, #26251e inverse dark band) paired with Geist and Geist Mono typography, sharp radii, and pill buttons.

STORY: Visitors immediately see Meet Rathod's four public projects cycling in the hero collage, explore interactive UI fragments and diagrams in the work grid, step through how Dueler, Mafioso, and PyRedis work in the pinned chapters band, inspect full project details in a spring drawer, and reach out directly.
